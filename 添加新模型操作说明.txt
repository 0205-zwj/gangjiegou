=====================================================
  钢结构构件一物一码系统 — 添加新模型操作流程
  制作人：赵文杰
=====================================================

【你需要准备什么】
  1. 一个新的 GLB 格式模型文件（比如 3.glb）
  2. 这个构件的基本信息（编号、加工号、项目名等）

-----------------------------------------------------
【第一步：压缩模型（必须做！否则加载很慢）】
-----------------------------------------------------

打开 PowerShell（在文件夹空白处按住Shift右键 → 在此处打开PowerShell），
输入以下命令（把 3.glb 换成你的文件名）：

  cd "E:\中铁装配\GitHub文档\gangjiegou\models"
  npx --yes @gltf-transform/cli@latest optimize 3.glb 3.min.glb --compress draco --texture-compress webp

等待跑完，你会看到类似：
  info: 3.glb (XX MB) → 3.min.glb (XX KB)

这样大文件就变小了（通常压缩到原来的5%~20%）。

-----------------------------------------------------
【第二步：把压缩后的文件放到 models 文件夹】
-----------------------------------------------------

确认文件在这里：
  E:\中铁装配\GitHub文档\gangjiegou\models\3.min.glb

（原来的大文件 3.glb 可以删掉，也可以留着备份）

-----------------------------------------------------
【第三步：修改 data.js 添加构件信息】
-----------------------------------------------------

用记事本或 VS Code 打开：
  E:\中铁装配\GitHub文档\gangjiegou\data.js

在最后一个构件的后面（最后一个 } 的前面），加上一段：

    ,
    "3": {
        partId: "3",
        workNo: "你的加工号",
        projectName: "昆明长水国际机场项目",
        section: "你的分部工程",
        partType: "你的构件类型",
        material: "你的材质",
        spec: "你的规格",
        quantity: "1套",
        glbUrl: "./models/3.min.glb"
    }

注意：
  - "3" 是构件编号，下一个新模型就用 "4"、"5" 依次递增
  - glbUrl 里的文件名要和你压缩后的文件一致
  - 前面的逗号不要漏！
  - 每个字段都填上真实信息

-----------------------------------------------------
【第四步：上传到 GitHub】
-----------------------------------------------------

1. 打开 GitHub Desktop
2. 左下角会看到有文件改动（index.html、data.js、models文件夹里的新文件）
3. 左下角 Summary 框里写一句：添加构件3
4. 点 "Commit to main" 按钮
5. 然后点右上角 "Push origin" 按钮上传
6. 等进度条跑完就成功了

-----------------------------------------------------
【第五步：访问测试】
-----------------------------------------------------

你的访问链接格式是：
  https://0205-zwj.github.io/gangjiegou/index.html?id=3

把 id=3 改成你新加的构件编号就行。

微信扫码的话，把这个链接生成二维码贴到构件上即可。

=====================================================
  常见问题
=====================================================

Q: 模型加载不出来？
A: 检查 glbUrl 路径对不对，文件名有没有打错，
   文件有没有真正上传到 GitHub。

Q: 模型太大压缩不动？
A: 正常，50MB的模型压缩到几百KB只需要几秒钟，耐心等。

Q: 想改现有构件的信息？
A: 直接改 data.js 里对应编号的字段就行，不用换模型。

Q: 想换模型？
A: 把新模型压缩成同名的 .min.glb 覆盖旧文件，然后上传即可。
   比如把新模型压缩成 2.min.glb 覆盖原来的 2.min.glb。
